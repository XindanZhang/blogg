Finally, I obtained a lifetime membership of of [Aldente](https://github.com/AppHouseKitchen/AlDente-Charge-Limiter). It's an (partially ?) open source application designed for Mac. The free version only provides access to two basic functions.

For free version users, not being able to access a comprehensive battery health monitoring dashboard and a pop-up window for showcasing the battery cycle count, battery temperature, and maximum capacity is really frustrating. Most importantly, you can set the `stop charging when sleeping` function to be `True` so as to prevent battery charging during sleep mode. With this application, we can use the charge limiter function to set the maximum charging percentage around 80%, which is probably the best charge level for battery longevity.
