# Router

## Overview
A router is a networking device that forwards data packets between computer networks. Routers perform the traffic directing functions on the Internet, connecting networks and determining the best path for data to travel.

## Types of Routers
- **Home/Consumer Routers**: Used in home networks to share internet connections
- **Enterprise Routers**: High-capacity routers used in large organizations
- **Core Routers**: Powerful routers used by ISPs to manage internet traffic
- **Edge Routers**: Connect internal networks to external networks like the internet
- **Virtual Routers**: Software-based routing implementations

## Router Functions
- Traffic forwarding between networks
- Packet filtering for security
- NAT (Network Address Translation)
- DHCP services
- Quality of Service (QoS) implementation
- VPN support
